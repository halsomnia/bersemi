# Tautan

Undangan digital. Mobile-first.

## Sekarang

- Katalog hanya tema **Hitam Putih** (editorial)
- Chip filter **Promo** sejajar kategori
- Kartu katalog menampilkan pratinjau sampul + **Lihat demo**
- Studio: undangan utuh + bar bawah Personalisasi / Order
- Slot foto (sampul, mempelai, galeri) memampatkan di perangkat. Unggah Supabase belum dihubungkan
- Draf tersimpan di `localStorage`

## Jalankan

```bash
npm install
npm run dev
```

Base path: `/Tautan/` (lihat `vite.config.js`).
